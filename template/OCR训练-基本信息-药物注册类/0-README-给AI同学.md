# OCR 训练资料包说明（给 AI 同学）

本包是「立项基本信息页 AI-OCR」的**药物 + 注册类**场景资料：字段契约、提取规则、示例输出和第一批训练样本。

## 文件清单与角色

| 文件 | 角色 | 说明 |
| --- | --- | --- |
| `1-空JSON-药物注册类.json` | **字段契约** | 38 个字段的 key/label/type/枚举选项/product[] 子字段结构。线上 OCR 请求实际携带的输入就是这个形态。 |
| `3-新对话提示词.md` | **提取规则（=标注规范）** | 输出格式、七条提取规则、输出要求。训练目标必须遵守这些规则。 |
| `2-示例-填好的JSON.json` | 格式教学样例 | 演示 value/confidence/source 写法、product[] 半填行（紫杉醇）。**SHR-1701 为虚构数据、无对应 PDF，不作为训练样本使用。** |
| `样例PDF-苹果酸阿莫曲坦片临床试验方案-CTS1248.pdf` | **训练样本① 输入** | 真实临床方案，42 页。 |
| `4-真实案例-苹果酸阿莫曲坦片-填好的JSON.json` | **训练样本① 标准答案** | 与上面 PDF 成对，输出 29/38 字段、缺省 9 个，已人工复核。 |
| `4-真实案例说明.md` | 样本① 讲解 | 逐条讲这份案例演示的规则点（宁缺勿错的 9 个缺省、安慰剂对照产品行、低置信日期归一等），可当标注 review 的参考答案。 |

## 训练样本怎么用

一个训练样本 = **PDF（输入） + 填好的 JSON（标准答案）**，成对使用。目前本包含 1 对真实样本（阿莫曲坦）；后续样本会按同格式追加（每对一组：`样例PDF-xxx.pdf` + `N-真实案例-xxx-填好的JSON.json`）。

## 核心规则速览（详见提示词）

1. 宁缺勿错：PDF 里找不到依据的字段，整个字段不输出。
2. enum 值必须严格命中 options 原文，归一不了就不输出。
3. date = `yyyy-MM-dd`；number = 纯数字。
4. product[]（联合/对照产品）：value 是对象数组，每行只写有依据的子字段（不造空串），枚举子字段命不中就省略；`name` 必填。
5. 每个输出字段带 `confidence`（0~1）和 `source`（具体出处，如「§6.2 研究用药」）。

## 输出形态对齐（重要）

训练 JSON 是 fields 形态；线上 OCR 服务响应契约为 `{recordId, status, items[{key, value, confidence, source}]}` 的 **items 形态**（见 wetrial 仓库 `设计方案/设计文档/技术方案-立项业务表单.md` §8.1）。两者映射 = fields 摊平成 items，最终模型输出用哪个形态请提前与我们约定，避免训练完再转换。
